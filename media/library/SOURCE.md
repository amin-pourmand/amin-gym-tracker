# Amino offline exercise-library media

The animated guides in this directory were generated locally from the two-step exercise images in [yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db), an Unlicense/public-domain dataset. Each source pair was resized, framed, animated, and converted into a compact looping MP4 for offline use in Amino.

`dead-hang.mp4` and `suitcase-carry.mp4` are original schematic animations generated for Amino because the source dataset did not include exact matching variants.

Generated: 2026-08-23
